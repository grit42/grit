`GritEntityRecord#detailed_scope` (and `Grit::Core::User.detailed`) alias each foreign key join as `<column>__` instead of `<table>__`, so a model can have two foreign keys to the same table. Raw SQL on top of `detailed` must reference e.g. `publication_status_id__.name` instead of `grit_core_publication_statuses__.name`.
