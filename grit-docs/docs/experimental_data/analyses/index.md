# Analyses

Analyses provide scientists and data managers with a way to visualise and analyse experimental data stored in an Data Sheet across Experiments. It is possible to include only a selection of Experiments, and filter the data sets with SQL-like conditions.

The resulting data set can be viewed in a table, and visualised in plots.
