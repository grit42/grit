# Platform administration

The grit platform can be managed by one or more users having the "admin:system" permission. User management requires the "admin:users" permission. The default _Administrator_  role and **admin** user have that permission by default and can be used to administer the platform.

:::caution
Users with the _Administrator_ role have no restrictions. Assign this role with caution.
:::
